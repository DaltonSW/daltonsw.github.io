{{/* Context: a game's term Page. Returns the most recent known activity date as a string, the max of: - every entry's finished date once it has one, otherwise the started date of whatever's still open (its last session if it has any, else the entry itself) — an ongoing entry's last known touch-point. - achievement-summary.yaml's last_played, when present: Steam's real last-played timestamp, or RetroAchievements' last-unlock date as its only available proxy (RA has no playtime/launch tracking at all) — see writeAchievementSummary in tools/gamelog. This can be more recent than any logged playthrough when a session hasn't been logged yet but achievements/playtime have been refreshed. Falls back to front-matter Params.finished/started only for games with nothing logged and no archived activity at all. hugo.toml's [frontmatter] config wires started/finished as .Date/.Lastmod sources, so Hugo hands back a time.Time instead of a string for whichever page actually uses one that way — piping through time.Format normalizes both to a plain "2006-01-02" string so the comparisons below never compare across mismatched types. */}} {{- $entries := partial "playthrough-entries.html" . -}} {{- $latest := "" -}} {{- range $entries -}} {{- $candidate := "" -}} {{- if gt (len .sessions) 0 -}} {{- $sorted := sort .sessions "started" "asc" -}} {{- $last := index $sorted (sub (len $sorted) 1) -}} {{- $candidate = $last.started -}} {{- with $last.finished -}}{{- $candidate = . -}}{{- end -}} {{- else -}} {{- $candidate = .started -}} {{- with .finished -}}{{- $candidate = . -}}{{- end -}} {{- end -}} {{- if and $candidate (or (eq $latest "") (gt $candidate $latest)) -}} {{- $latest = $candidate -}} {{- end -}} {{- end -}} {{- with .Resources.Get "achievement-summary.yaml" -}} {{- with (. | transform.Unmarshal).last_played -}} {{- if or (eq $latest "") (gt . $latest) -}}{{- $latest = . -}}{{- end -}} {{- end -}} {{- end -}} {{- if eq $latest "" -}} {{- with .Params.finished -}}{{- $latest = (. | time.Format "2006-01-02") -}}{{- end -}} {{- if eq $latest "" -}} {{- with .Params.started -}}{{- $latest = (. | time.Format "2006-01-02") -}}{{- end -}} {{- end -}} {{- end -}} {{- return $latest -}}
