Catch up's "Load what's new" already refreshes every provider. These are the manual versions: one provider at a time, or a full re-fetch. Per-game refresh lives on each game's own page.

refresh

Fetches every linked game's unlock history from every provider it's linked to — or, with a provider button, only that provider's link on the games that have one. RA throttles to ~1.2s/request, so with 200+ linked games this can take several minutes — runs as a background job you can watch progress on. Steam games whose playtime and last-played date haven't moved since the last fetch are skipped; tick the box to re-fetch those too (worth doing now and then, since offline unlocks can sync without moving either).
