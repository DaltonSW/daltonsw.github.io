Achievements

Per-game refresh lives on each game's own page. These two act across the whole library.

refresh all

Fetches every linked game's unlock history from RetroAchievements/Steam. RA throttles to ~1.2s/request, so with 200+ linked games this can take several minutes — runs as a background job you can watch progress on.

regenerate summaries

Rebuilds every game's achievement-summary.yaml from what's already archived on disk. No API calls — safe and fast to re-run any time.
